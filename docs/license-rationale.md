# License Rationale

Docksmith is changing from Apache-2.0 to MPL-2.0.

MPL-2.0 is a file-level copyleft license. If someone modifies Docksmith source
files or contributes new files that contain Docksmith code, those Docksmith
blueprint improvements must remain available under MPL-2.0 when distributed.
That protects the framework detection, planning, and Dockerfile generation work
that makes Docksmith useful.

At the same time, MPL-2.0 permits larger works to use their own licensing. Apps
that consume Docksmith, platforms that embed the library or CLI, deployment
systems that call it, and Dockerfiles generated by Docksmith can remain
proprietary or use any other license chosen by their owners, as long as the
MPL-2.0 requirements for Docksmith-covered source files are met.

## Migration Note

Earlier Docksmith releases were documented as Apache-2.0. Existing copies that
were received under Apache-2.0 remain governed by the license terms that applied
to those copies. New Docksmith source distributions after this change should use
MPL-2.0 and include the top-level [LICENSE](../LICENSE).

questions.
