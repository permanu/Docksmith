# License Headers

Docksmith source files are licensed under the Mozilla Public License 2.0
(`MPL-2.0`) as described by the repository-level [LICENSE](../LICENSE), even
when an individual source file does not include its own license header.

The absence of a per-file header should not be interpreted as an absence of
license coverage. Source distributions should keep the top-level `LICENSE`
file with the repository so recipients can identify the applicable terms.

For new source files, prefer adding a short SPDX header:

```text
SPDX-License-Identifier: MPL-2.0
```

Use the comment syntax appropriate for the file type. Existing files do not
need to be mass-edited only to add this header.

This note is for project licensing clarity and is not legal advice.
